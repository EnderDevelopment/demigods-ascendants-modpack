# Demigods Ascendants Modpack

The Demigods Ascendants Modpack is a Minecraft modpack designed to enhance the exploration, building, and visual appeal of the game. It is based on the Demigods Ascendants mod, which adds a variety of new creatures, structures, and mechanics to the game. The modpack is built for NeoForge 1.21.1 and includes Lumen Forge for improved lighting and performance. It is not compatible with Iris.

## Install

1. Download the modpack from the GitHub repository.
2. Extract the downloaded file to a new folder.
3. Open the folder and run the `install.bat` file to install the required mods.
4. Launch the modpack using the `launch.bat` file.

## Use

1. Launch the modpack using the `launch.bat` file.
2. Create a new world or load an existing one.
3. Explore the new biomes, structures, and creatures added by the Demigods Ascendants mod.
4. Build and craft using the new items and blocks added by the modpack.
5. Enjoy the improved lighting and performance provided by Lumen Forge.
